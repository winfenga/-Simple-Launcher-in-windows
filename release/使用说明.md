# 🚀 我的启动器（可视化本地启动器）v1.2

把 **BAT / EXE / Python 脚本 / 文件夹 / 网址** 拖进来，起个中文名、配个图标，点一下就打开；
配好快捷键后，**任何界面按一下就能唤出它**。

> 专门为「路径必须是英文、但自己想看中文名」这种场景做的。

---

## 一、v1.2 新增了什么

### 1. 全局快捷键唤出（新）
- 默认 **`Ctrl+Alt+Space`**：在任何程序里按一下，启动器立刻跳到最前面，光标自动落在搜索框；
  再按一下，窗口收回去。
- 想换成顺手的组合：**右上角「⌨ Ctrl+Alt+Space」按钮**，或 **☰ 菜单 → ⌨ 快捷键设置**。
- 设置窗口是「录制式」的：点一下框，直接按下你想要的组合键就行；
  也可以点「常用组合」里的 `Ctrl+Shift+Space` / `Alt+Q` / `Ctrl+Alt+L`。
- 规则：**至少带一个修饰键**（Ctrl / Alt / Shift / Win）+ 一个按键（字母、数字、F1~F24、空格、方向键等）。
- 如果这个组合已经被别的软件占用，会明确告诉你「已被占用」，不会默默失效。
- 不想要它，菜单里取消勾选「启用全局快捷键」即可。

### 2. 添加启动项有引导了（新）
以前的添加窗口是一片空表单，现在：

| 引导 | 说明 |
|------|------|
| 分步表单 | ① 要启动什么 → ② 显示名称 → ③ 启动方式 → ④ 图标与选项，每步都写着「必填 / 可跳过」 |
| 类型化提示 | 选完文件后，灰框里会告诉你这类文件要注意什么（bat 为什么要填工作目录、py 要不要黑窗…） |
| ✨ 推荐设置 | 一键按文件类型填好工作目录、控制台窗口、名称、图标 |
| ▶ 试运行 | 先按当前设置启动一次看看效果，**不会保存、不会关闭窗口** |
| 原地提示 | 少填了东西会在窗口底部提示并高亮，不再弹一堆系统小窗 |
| 首次引导 | 第一次运行会弹出「使用引导」（4 步），菜单 ☰ → ❓ 使用引导 里可以随时再看 |

### 3. 界面重做（新）
- 卡片、列表、按钮、输入框全部改成**圆角自绘**，悬停时描边变主题色
- 深色 / 浅色两套配色都重新调过，切换按钮在右上角
- 分组徽章、置顶 📌、启动次数等细节重新排版
- 内容不多时滚动条自动隐藏；空列表有引导按钮，不再是干巴巴一行字

### 4. 重复打开不再弹「已经运行了」（新）
- 以前启动器已经在跑时，再双击图标只会弹一个提示框，什么也干不了
- 现在会**直接把已经开着的那个窗口叫出来**（藏在托盘里 / 最小化了都能拉出来）
- 实现上用的是本地回环端口 + 事件轮询，不去碰 Tk 的消息循环，稳

### 5. 键盘操作（新）
- 唤出窗口后**直接打字**就是搜索，不用先点搜索框
- `↑` `↓` 选项目（选中项有主题色描边），`Enter` 直接启动
- `Home` / `End` 跳到第一个 / 最后一个，`Esc` 清空搜索，`Ctrl+F` 定位搜索框，`F5` 刷新
- 配合全局快捷键就是「按一下 → 打两个字 → 回车」的完整流程

### 6. 其它小改进（新）
| 功能 | 在哪 | 说明 |
|------|------|------|
| 排序方式 | ☰ 菜单 → 排序方式 | 按名称 / 常用优先（按启动次数排） |
| 启动时隐藏窗口 | ☰ 菜单 | 开机自启时静悄悄缩在托盘里，用快捷键唤出 |
| 点到别处自动收起 | ☰ 菜单 | 像 Spotlight 那样失焦自动隐藏（默认关） |
| 托盘常用项 | 托盘右键 | 托盘菜单里直接列出最常用的 6 个项目，点一下就跑 |
| 输入框美化 | 全局 | 搜索框 / 表单框都是圆角 + 聚焦高亮 |

### 7. 更强的整理能力（新）
- **多层分组**：分组字段写 `开发/前端` 就是两级；筛选下拉里按层级显示，选「开发」会带出它下面所有子分组
- **拖拽排序**：菜单里把排序方式切成「手动排序」，之后直接拖动卡片调整位置（拖到哪插到哪，有插入线提示）；
  筛选状态（搜索/分组）下不能拖，会提示你先清空筛选
- **失效路径体检**：☰ 菜单 → 🩺 体检，一次列出所有打不开的项目（文件被删/移动/改盘符），
  勾选后可以**就地重新指定**或批量删除

### 8. 更快的添加方式（新）
| 功能 | 在哪 | 说明 |
|------|------|------|
| 桌面 / 开始菜单导入 | ＋ 添加 或 ☰ 菜单 | 自动扫出桌面 + 开始菜单里的快捷方式（本机 176 个），按它们所在的文件夹自动分好组，勾选即导入；能解析 .lnk 的真实目标 |
| 资源管理器右键 | ☰ 菜单勾选「资源管理器右键『添加到启动器』」 | 开启后，任意文件 / 文件夹上右键就多一项「添加到启动器」；启动器没开的话会自动开 |
| 快速新建 | 界面空白处右键 / ＋ 添加 | 新建文件夹 / BAT 脚本 / TXT 文本，建完可直接加入启动器；BAT 自带 GBK 模板（中文不乱码、跑完停住看结果） |

### 9. 更多快捷方式（新）
- **单项独立快捷键**：在添加/编辑窗口的第 ④ 步录制（比如 `Ctrl+Alt+1`），任何界面按一下直接启动它；
  和「唤出启动器」或别的项目撞车会在保存时提醒
- **启动链 / 工作模式**：☰ 菜单 → 🔗 启动链，把几个项目串成一条链（可设间隔秒数），
  点「▶ 运行」依次拉起，比如「开工模式」= 编辑器 → 终端 → 项目文件夹

### 10. 更贴合系统（新）
- **主题跟随系统**：☰ 菜单 → 主题 → 跟随系统，Windows 切深色它就跟着切（还会每 20 秒自动跟一次）
- **拼音首字母搜索**：打 `jst` / `js` 就能搜到「记事本」，`kfzd` 搜到「开发终端」；
  中文名不用切输入法也能搜

### v1.1 修过的问题（仍然有效）
1. 命令行窗口**乱码** —— 启动脚本改成 GBK、不再中途切码页
2. 命令行窗口**不自动关闭** —— 启动脚本用 `pythonw` / VBS 无窗口拉起
3. 启动项**和启动器控制台绑定** —— `.py` 用 `pythonw`、`.bat` 在独立新控制台里跑
4. 新增 **工作目录**、**启动参数** 两个字段
5. 高 DPI 不模糊、任务栏图标、图标缓存、窗口越界修正、单实例、崩溃日志

## 二、快速开始（两种方式）

### 方式 A：直接用（推荐，先试这个）
1. 电脑装好 **Python 3.8+**（安装时务必勾选 `Add Python to PATH`）
2. 把整个文件夹放到你想放的地方
3. 双击 **`启动.bat`**
   - 第一次会自动装依赖（pillow / pywin32 / tkinterdnd2 / pystray），十几秒
   - 之后每次双击都能直接跑，**黑窗口一闪就自动关闭**
4. 想要完全看不到黑窗口，双击 **`启动-无窗口.vbs`**（适合放桌面 / 开机启动）

### 方式 B：打包成独立 exe（可以拷到别的电脑用）
1. 双击 **`打包成exe.bat`**
2. 完成后得到 `dist\启动器.exe`，双击即用，**不需要装 Python**
3. 把它复制到任意文件夹，配置和图标会保存在 exe 同目录下
   > 打包前记得先退出正在运行的旧版 exe，否则文件被占用会打包失败

## 三、怎么用

### 添加启动项
- 点右上角 **「＋ 添加」**：可以选添加程序/脚本、添加文件夹、添加网址
- 或者 **直接把文件拖进窗口**（支持一次拖多个）
- 添加窗口里会一步步引导你填：

| 项目 | 说明 |
|------|------|
| ① 路径 / 网址 | **必填**。也是唯一必填项 |
| ② 名称 | 你想看的中文名，比如「每日备份脚本」；留空会自动用文件名 |
| ② 分组 | 比如「工作 / 游戏 / 工具」，之后可以按组筛选 |
| ③ 控制台窗口 | 自动（推荐）/ 始终显示 / 始终隐藏，见下表 |
| ③ 工作目录 | 留空 = 用文件所在目录。**BAT 报找不到文件时，填成脚本所在文件夹** |
| ③ 启动参数 | 传给程序的命令行参数，一般留空 |
| ④ 图标 | **自动从 EXE 提取**；也可以自己选 PNG / ICO |
| ④ 选项 | 以管理员身份运行（会弹 UAC）、置顶显示 |

**控制台窗口怎么选**

| 目标类型 | 自动（默认）行为 |
|----------|------------------|
| `.py` | 用 `pythonw` 启动，**不弹黑窗**；想看 print 输出就选「始终显示」 |
| `.bat` / `.cmd` | 弹出**独立**窗口，脚本跑完**自动关闭**（脚本里有 `pause` 就会等你按键） |
| `.ps1` | 独立 PowerShell 窗口 |
| `.exe` | 走系统方式启动，GUI 程序不会有黑窗 |

| 文件 | 作用 |
|------|------|

## 六、常见问题

**Q：快捷键按了没反应？**
A：① 先看右上角按钮是不是显示「⌨ 快捷键已关」，是的话在菜单里勾选「启用全局快捷键」；
② 组合可能被别的软件抢占，去「⌨ 快捷键设置」换一个（例如 `Ctrl+Alt+L`）；
③ 有些游戏 / 全屏程序会独占键盘，切回桌面再试。

**Q：怎么改快捷键？**
A：点右上角的 `⌨ …` 按钮，在框里直接按新的组合键，点「保存」。

**Q：双击 `启动.bat` 时黑窗口一闪就没了，程序也没开？**
A：看同目录下的 `launcher_error.log`，里面是具体报错。

**Q：BAT 一闪而过 / 报找不到文件？**
A：在编辑里把「工作目录」填成 BAT 所在的文件夹（点「✨ 推荐设置」会自动填好）。

**Q：Python 脚本运行没窗口 / 看不到 print 输出？**
A：`.py` 默认用 `pythonw` 启动，所以没有黑窗。想看输出就把「控制台窗口」改成「始终显示控制台窗口」。

**Q：拖文件没反应？**
A：拖拽依赖 `tkinterdnd2`。重启一次程序；还不行就 `pip install tkinterdnd2`。

**Q：想让程序开机自启？**
A：☰ 菜单 → 勾选「开机自动启动」，写的是注册表 `Run` 项。

**Q：点右上角 × 关不掉？**
A：开启了托盘的话，× 是最小化到托盘。托盘图标右键 → 退出，或在 ☰ 菜单里关掉托盘。

**Q：提示「启动器已经在运行」？**
A：现在**不会**再弹这个提示了：再双击一次图标，会把已经开着的那个窗口直接叫出来
（藏在右下角托盘里、最小化了、被别的窗口挡住都能拉出来）。同一时间仍然只有一个实例在跑。

**Q：怎么一次把桌面/开始菜单里的软件都收进来？**
A：点「＋ 添加 → 📥 从桌面 / 开始菜单导入…」，会自动扫出来（本机一百多个），
按它们所在的文件夹自动分好组，勾选后点「导入选中项」。已经在列表里的会标出来，不会重复加。

**Q：右键菜单里没有「添加到启动器」？**
A：这个功能默认关着（要写注册表）。到 ☰ 菜单里勾选「资源管理器右键『添加到启动器』」，
之后任意文件 / 文件夹上右键就有了。不想用了再取消勾选即可，注册表项会被清掉。
注意：打包成 exe 后如果移动了 exe 的位置，重新勾一次让路径更新。

**Q：怎么把常用的几项排到顺手的位置？**
A：☰ 菜单 → 排序方式 → **手动排序**，然后直接拖动卡片：会有一条插入线告诉你将插到哪。
在手动排序模式下右键「置顶」= 挪到最前面。

**Q：搜索能打拼音吗？**
A：可以。中文名支持首字母，比如「记事本」打 `jsb` 或 `js` 就能搜到；
中英文混排的名字（如 `GitHub`）直接打原文或首字母都行。

**Q：怎么一键打开一整套环境？**
A：☰ 菜单 → 🔗 启动链 / 工作模式 → 新建启动链，勾选要一起启动的项目、设好间隔秒数。
以后点「▶ 运行」就会按顺序依次启动。

**Q：能不能让某个项目有专属快捷键？**
A：可以。编辑项目 → 第 ④ 步「专属快捷键」，点一下框再按组合键（例如 `Ctrl+Alt+1`）。
以后在任何界面按它就直接启动这一项。和「唤出启动器」的快捷键撞车时会提示你换一个。

**Q：新建的 BAT 打开是乱码？**
A：新建的 BAT 是 **GBK 编码**（配合 `chcp 936`），用记事本打开正常。
如果你用 VS Code 之类打开，它可能按 UTF-8 猜而显示乱码，改成 GBK/ANSI 编码查看即可——
**不要**另存为 UTF-8，否则命令行里中文会乱。

**Q：体检说某些项目打不开怎么办？**
A：勾选它们，点「重新指定选中项」逐个选新位置（图标会一起更新）；确定不要了就点「删除选中项」。

**Q：配置丢了怎么办？**
A：每次保存都会留一份 `launcher_config.bak.json`，把它的内容复制回 `launcher_config.json` 即可。

**Q：我改了点代码，怎么让 exe 也更新？**
A：先退出正在运行的 `启动器.exe`，再双击 `打包成exe.bat`。

## 七、想改点什么

代码在 `launcher.py` 里：

- 想改颜色 / 圆角 → 顶部 `THEMES` 字典、`CARD_W` / `CARD_H`、`draw_round()` 的 `radius`
- 想改默认快捷键 → `DEFAULT_HOTKEY`
- 想改添加窗口里的引导文案 → `ItemDialog._analyze()` 和 `GUIDE_STEPS`
- 想改默认窗口大小 / 默认视图 / 默认排序 → `DEFAULT_CONFIG`
- 想改启动方式（比如让 `.py` 默认也弹窗）→ `plan_launch()`
- 快捷键键位表 → `VK_TABLE` / `VK_LABEL`
- 第二实例唤出用的端口 → `IPC_PORT`（默认 52117，被占用时会自动降级，不影响使用）
